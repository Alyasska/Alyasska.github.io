# Aliaskar Bekishev — character sheet

My portfolio, built as an old-school RPG character sheet. Plain HTML/CSS/JS,
no build step, no frameworks — just open `index.html` or serve the folder.

- `character.js` — all the data (stats, quests, pets, guilds)
- `app.js` — renders the sheet
- `mapbg.js` — the living ASCII island background
- `fx.js` · `overlay.js` — cursor, parallax, and ambient ASCII effects (birds, clouds)
- `styles.css` — the light "corporate game-UI" theme
